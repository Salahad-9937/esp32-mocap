# ESP32 IMU MoCap System

Аппаратно-программный комплекс захвата движений (Motion Capture) на базе микроконтроллера ESP32, коммутаторов шины I2C и инерциальных измерительных модулей (IMU).

Проект решает задачу высокоскоростного беспроводного сбора первичной кинематической телеметрии (ускорений и угловых скоростей) с произвольного числа участков тела или подвижных звеньев механизмов без использования тяжелых алгоритмов фильтрации на микроконтроллере.

## 1. Архитектура и состав комплекса

Комплекс строится по модульной схеме с асимметричным разделением вычислительной нагрузки:

* **Аппаратная часть:**
  * Концентратор: микроконтроллер ESP32-WROOM-32 на плате расширения со стабилизированным питанием 3.3 В.
  * Коммутация: от 1 до 8 мультиплексоров PCA9548A (аппаратные адреса I2C от `0x70` до `0x77`).
  * Датчики: от 1 до 64 шестиосевых инерциальных модулей Bosch Sensortec BMI160 (акселерометр $\pm 4g$ + гироскоп $\pm 1000^\circ/\text{с}$).
* **Прошивка микроконтроллера (`firmware/`):**
  * Прямой регистровый опрос датчиков по шине I2C (Fast Mode 400 кГц) без сторонних библиотек.
  * Аппаратный автопоиск подключенных мультиплексоров и активных датчиков при старте.
  * Упаковка сырых 16-битных целочисленных измерений в бинарный кадр с преамбулой и контрольной суммой CRC-16.
  * Беспроводная потоковая передача кадров по протоколу Bluetooth Classic SPP на частоте 60–80 Гц.
* **Библиотека обработки на ПК (`crates/mocap-core/`):**
  * Встраиваемый headless-крейт на языке Rust без графических зависимостей.
  * Чтение виртуального последовательного порта Bluetooth, потоковое кадрирование и проверка CRC.
  * Статическая калибровка смещения нуля гироскопа (Zero-Rate Bias) и перевод кодов в физические величины СИ.
  * Хранение ассоциативных профилей сопоставления каналов датчиков с костями скелета (маппинг в TOML).
  * Открытый полиморфный конвейер фильтрации ориентации (трейт `OrientationFilter`, фильтры Madgwick, Mahony и режим прямого пропуска Bypass).
* **Эталонное приложение настройки (`src/`):**
  * Графический клиент на Rust (Composition Root проекта).
  * Диагностика связи, индикация частоты кадров и целостности пакетов.
  * Матрица активных узлов шины I2C в реальном времени.
  * Многоканальный осциллограф первичных сигналов.
  * Интерактивный мастер привязки датчиков к анатомическому скелету и пошаговая калибровка нулей.
  * Проволочный 3D-визуализатор пространственной позы.

## 2. Документация проекта

Подробная спецификация разделена на два изолированных комплекта документов:

* **[Границы и системный регламент проекта](docs/boundaries/index.md):**
  * Определение человекомерности и концепция открытого аппаратного конструктора (масштабирование от 1 до 64 датчиков).
  * Модульное описание сенсорной подсистемы, мультиплексирования, контроллера, хост-библиотеки и эталонного UI.
  * Категорический перечень технических ограничений и Non-Goals проекта.
* **[Техническая архитектура и спецификация реализации](docs/architecture/index.md):**
  * Общесистемный сквозной поток данных, расчет бюджета времени шины I2C и радиоканала Bluetooth SPP.
  * Архитектура прошивки ESP32: протокол сброса зависшей шины (Clock Pulsing), регистры BMI160, временные задержки переключения питания.
  * Архитектура библиотеки `mocap-core`: структура потокового кадрировщика, математическая модель калибровки и конвейера Sensor Fusion.
  * Архитектура приложения `src/`: модель разделения потоков ввода-вывода и рендеринга, структура панелей интерфейса.

## 3. Команды сборки и автоматизации (justfile)

Для выполнения рутинных задач разработки используется утилита `just`:

* **`just doc`** — компиляция документации из каталога `docs/` в формат PDF с использованием Pandoc и XeLaTeX. Скомпилированные файлы размещаются в `docs/dist/`.
* **`just ctx`** — сборка и запуск интерактивного терминального менеджера контекста (`mocap-context`) для формирования единого среза кодовой базы проекта (`project_context.txt`).
* **`just`** (без параметров) — выполнение команды по умолчанию (`just doc`).
