# 5. Программная библиотека обработки данных на ПК {#sec-processing-library}

## 5.1. Назначение и архитектурная роль Rust-библиотеки

Библиотека обработки представляет собой **независимый программный модуль на языке Rust**, функционирующий на стороне компьютера и не имеющий графических зависимостей (Headless Library / Crate).

Ее задача — предоставить универсальный, типобезопасный программный интерфейс (API) для подключения к потоку данных аппаратного комплекса, валидации кадров, калибровки датчиков и трансляции физических сигналов в любые внешние проекты.

### Ключевые архитектурные свойства:
* **Встраиваемость:** Библиотека может быть подключена в любой внешний процесс: физический симулятор, робототехнический узел, консольную утилиту логирования или графическое приложение.
* **Изоляция микроконтроллера:** Микроконтроллер ESP32 не хранит логику калибровки или маппинга. Вся обработка, интерпретация каналов и компенсация аппаратных смещений выполняются внутри библиотеки на мощностях процессора ПК.
* **Отсутствие графических привязок:** Библиотека оперирует исключительно математическими структурами данных, потоками байтов и конфигурационными файлами.

## 5.2. Потоковый транспорт и декодирование протокола

* **Интерфейс подключения:** Библиотека обеспечивает кроссплатформенное чтение виртуального последовательного порта Bluetooth (в Linux — `/dev/rfcommX`, в Windows — `COMx`) либо стандартного проводного USB-UART соединения.
* **Потоковый кадрировщик (Stream Framer):**
  * Побайтовое сканирование входящего буфера для синхронизации по стартовой сигнатуре `0xAA 0x55`.
  * Извлечение 16-битного счетчика кадров для непрерывного отслеживания стабильности радиоканала и фиксации потерь пакетов.
  * Чтение динамического счетчика узлов $N$, определяющего длину текущей полезной нагрузки.
  * Верификация контрольной суммы (CRC). Пакеты с нарушенной целостностью детерминированно отбрасываются без потери синхронизации потока.
* **Десериализация данных:** Преобразование последовательности байтов каждого узла в 16-битные знаковые целочисленные коды измерений ($Ax, Ay, Az, Gx, Gy, Gz$).

## 5.3. Модуль калибровки и нормализации сигналов

Библиотека обеспечивает программную компенсацию погрешностей датчиков без перепрошивки микроконтроллера:

* **Статическая калибровка смещения гироскопа (Zero-Rate Bias):**
  * По команде пользователя или при старте сессии в состоянии покоя библиотека накапливает массив измерений за заданный временной интервал.
  * Вычисляется среднее статическое смещение нуля по каждой оси для всех активных датчиков.
  * Вектор смещения сохраняется в состоянии библиотеки и автоматически вычитается из входящих угловых скоростей в реальном времени.
* **Масштабирование в физические единицы СИ:**
  * Пересчет сырых кодов АЦП с учетом аппаратных диапазонов $\pm 4g$ и $\pm 1000^\circ/\text{с}$.
  * Выдача ускорений в метрах на секунду в квадрате (м/с² или единицах $g$) и угловых скоростей в радианах в секунду (рад/с) либо градусах в секунду.

## 5.4. Слой абстракции топологии и маппинга (Sensor Mapping)

Поскольку аппаратный комплекс поставляет данные под обезличенными индексами каналов, библиотека предоставляет механизм логического сопоставления:

* **Таблица сопоставления (Mapping Table):** Ассоциативный массив, связывающий пару «Индекс мультиплексора — Номер канала» с семантическим идентификатором целевого сегмента (например, строковым тегом, перечислением костей скелета или идентификатором звена манипулятора).
* **Сериализация профилей:** Загрузка и выгрузка конфигураций привязки в структурированные текстовые форматы (например, TOML/JSON) на диске хост-системы.
* **Фильтрация отключенных узлов:** Библиотека автоматически сопоставляет фактически полученный бинарный срез с активным профилем маппинга, сигнализируя приложению о доступности конкретных сегментов.

## 5.5. Модульная архитектура ориентации и фильтрации (Sensor Fusion Pipeline)

Для исключения жесткой привязки к единственному алгоритму библиотека предоставляет **открытый модульный конвейер фильтрации**:

* **Абстрактный интерфейс фильтрации:**
  * Библиотека определяет унифицированный программный контракт шага фильтрации.
  * Контракт принимает вектор калиброванных измерений (линейные ускорения, угловые скорости и квант времени $\Delta t$) и возвращает единичный кватернион пространственной ориентации $q = [w, x, y, z]$.
* **Встроенные готовые алгоритмы:**
  * Библиотека предоставляет несколько стандартных предустановленных реализаций (например, классический фильтр Маджвика, фильтр Махони или базовый комплементарный фильтр), готовых к использованию без дополнительного кодирования.
* **Пользовательские реализации:**
  * Разработчик может реализовать собственный алгоритм фильтрации (например, расширенный фильтр Калмана EKF или специфическую модель коррекции) и передать его в конвейер библиотеки в качестве активного обработчика узлов.
* **Режим прямого доступа (Bypass Mode):**
  * Любая фильтрация ориентации может быть полностью отключена.
  * В этом режиме библиотека выдает потребителю чистый синхронизированный поток калиброванных ускорений и угловых скоростей, позволяя выполнять всю математическую обработку целиком на стороне внешнего приложения.
