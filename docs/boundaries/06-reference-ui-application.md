# 6. Эталонное приложение интерфейса и настройки {#sec-reference-ui-application}

## 6.1. Назначение эталонного UI

Эталонное графическое приложение представляет собой **минимальный, полностью функциональный пример интеграции библиотеки обработки на языке Rust**.

Приложение решает задачу первоначальной настройки оборудования, визуальной проверки качества сигналов, интерактивной привязки датчиков и калибровки системы оператором.

### Системный статус приложения:
* **Референсный пример:** Код приложения демонстрирует сторонним разработчикам правильные паттерны вызова API библиотеки обработки (подключение к порту, чтение потока, калибровка, экспорт).
* **Автономия от микроконтроллера:** Приложение взаимодействует исключительно с локальной Rust-библиотекой. Прошивка ESP32 не содержит кода, специфичного для данного интерфейса, и не меняет логику работы в зависимости от наличия открытого окна программы.

## 6.2. Функциональный состав интерфейса

Графический интерфейс предоставляет оператору следующие рабочие панели:

* **Панель подключения и статуса связи:**
  * Выбор и открытие системного порта (Bluetooth виртуальный COM-порт или USB-UART).
  * Индикация частоты поступления пакетов (Гц), счетчика принятых кадров и количества отброшенных поврежденных пакетов (CRC Error Counter).
* **Панель топологии и мониторинга оборудования:**
  * Наглядное отображение обнаруженных микросхем мультиплексоров на шине I2C.
  * Матрица активных каналов с подсветкой статуса: «Подключен и исправен», «Пустой канал», «Сбой связи».
* **Осциллограф и инспектор первичных сигналов:**
  * Вывод числовых значений и динамических графиков ускорений ($Ax, Ay, Az$) и угловых скоростей ($Gx, Gy, Gz$) для выбранного датчика.
  * Быстрая визуальная диагностика шумов, проверка ориентации осей и проверка механического крепления модулей.
* **Интерактивный конфигуратор привязки (Visual Mapper):**
  * Схематичное представление модели тела или списка целевых сегментов.
  * Интерактивное назначение: оператор выбирает активный узел из списка обнаруженных и привязывает его к нужной кости скелета (например, шевелит предплечьем, видит отклик на графике и нажимает «Назначить на правое предплечье»).
  * Сохранение созданной таблицы привязки в именованный файл профиля на диске ПК.
* **Мастер калибровки нулей (Calibration Wizard):**
  * Пошаговый сценарий статической калибровки гироскопов: инструкция оператору сохранить неподвижность, запуск сбора выборки через библиотеку, прогресс-бар накопления измерений и подтверждение успешной фиксации нулевых поправок.
* **Проволочная 3D-визуализация ориентации:**
  * Схематичное отображение сегментов скелета или 3D-осей ориентации датчиков в пространстве на базе кватернионов, рассчитанных библиотечным модулем ориентации, для визуального подтверждения корректности настройки.

## 6.3. Границы функционала UI

* Приложение не является тяжелым редактором анимаций или игровой средой.
* Приложение не осуществляет сложный физический рендеринг, симуляцию окружения или скелетный скиннинг персонажей. Его задача ограничена верификацией оборудования, калибровкой и сохранением профилей конфигурации.
