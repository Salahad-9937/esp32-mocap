# 3D Mesh Asset Pipeline :: Mannequin Geometry

## 1. Первоисточник и лицензия
* **Модель:** Prototyping Mannequin (автор: `burning-barb`).
* **Лицензия:** Creative Commons CC0 1.0 Universal (Public Domain).
* **Файл исходника:** `assets/mannequin.blend` (1.1 МБ).

## 2. Конвейер экспорта (Asset Pipeline)
Экспорт геометрии в движок осуществляется в фоновом режиме через Blender CLI:
```bash
blender -b assets/mannequin.blend -P tools/export_mannequin.py
# или через just:
just export-mesh
```

## 3. Архитектурные преобразования геометрии
1. **Преобразование T-Pose -> N-Pose:**
   * Звенья рук (начиная с плечевой кости) поворачиваются вокруг центра плечевого сустава ($X = \pm 0.178$, $Z = 1.338$ м) на $90^\circ$ вниз вдоль туловища.
2. **Конвертация осей координат:**
   * Из системы Blender ($Z$ вверх, $-Y$ вперед) в систему проекта/OpenGL ($Y$ вверх, $+Z$ вперед, лицо в $+Z$):
     $$X_{mocap} = X_{blender}, \quad Y_{mocap} = Z_{blender}, \quad Z_{mocap} = -Y_{blender}$$
3. **Сферизация шарниров:**
   * Шарниры плеч, локтей, запястий, тазобедренных, коленных, голеностопных и межфаланговых сочленений заменены на процедурные UV-сферы соответствующих анатомических радиусов с центром в центроиде сочленения.
   * Шарниры шеи, талии и сустава пальцев стопы сохранены из оригинального меша.
4. **Формат бинарного контейнера `MOCAP_MESH_V3` (`mannequin.bin`):**
   * Сигнатура: `MOCAP_MESH_V3\0` (14 байт).
   * Блок мешей: количество, теги костей, материалы `Tone`, массивы вершин, нормалей и треугольных индексов.
   * Блок сенсоров: 64 площадки IMU (позиция на поверхности, внешняя нормаль, тангенс).
   * Блок суставов: 51 сочленение кинематического дерева с точной иерархией `parent_idx`.
